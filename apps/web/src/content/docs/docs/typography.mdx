Kemet UI allows you to control the rhythm of any text element by using the Styles API Text utility.


<CodePreview>
  <p data-kemet="text:xs">This is extra small text</p>

  <p data-kemet="text:sm">This is small text</p>

  <p data-kemet="text:md">This is medium text</p>

  <p data-kemet="text:lg">This is large text</p>

  <p data-kemet="text:xl">This is extra large text</p>

  <p data-kemet="text:2xl">This is 2x large text</p>

  <p data-kemet="text:3xl">This is 3x large text</p>

  <p data-kemet="text:4xl">This is 4x large text</p>

  <p data-kemet="text:5xl">This is 5x large text</p>
</CodePreview>

See the [Text Styles API documentation](/styles/text) for more information.
