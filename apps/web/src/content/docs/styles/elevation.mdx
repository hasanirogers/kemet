The `elevation` style utility allows you to add box shadows to elements. It supports various layer depths. Here's an example configuation for the API.


<CodePreview>
  <div data-kemet="elevation:3 padding:2xl margin:2xl">
    <span>The quick brown fox jumps over the lazy dog.</span>
  </div>
</CodePreview>

[Use Storybook to generate configuations](https://storybook.kemet.dev/?path=/story/styles-api-border--standard) and to get a better understanding of the options available.
