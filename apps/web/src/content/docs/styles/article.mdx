      <h2>Introduction</h2>
      <p>
        Building accessible and semantic websites requires a deep understanding of
        HTML elements. While many developers rely solely on
        <code>&lt;div&gt;</code> tags, HTML offers a rich vocabulary for styling
        and structuring content natively.
      </p>
      <p>
        For instance, we can highlight critical text using the
        <mark>highlighted mark tag</mark>, show
        <strong>strong importance</strong>, or simply add
        <em>semantic emphasis</em>. When citing sources like
        <cite>The Web Standards Handbook</cite>, proper tags ensure screen readers
        interpret the context accurately.
      </p>
      <p>
        We can also represent mathematical formulas like H<sub>2</sub>O or 2<sup>10</sup>
        = 1024, as well as strike through
        <s class="outdated">outdated information</s> and replace it with
        <ins>updated corrections</ins> or <del>deleted text</del>.
      </p>
    </section>

      <h2>Obscure Inline Elements</h2>
      <p>
        Here are several lesser-known elements that add semantic meaning to
        specific types of text:
      </p>
      <ul>
        <li>
          <strong>Definitions:</strong> The
          <dfn title="A lightweight data-interchange format">JSON</dfn> format is
          widely used for web APIs.
        </li>
        <li>
          <strong>Bi-Directional Override:</strong>
          <bdo dir="rtl">This text will be rendered from right to left.</bdo>
        </li>
        <li>
          <strong>Bi-Directional Isolation:</strong> User
          <bdi>إبراهيم</bdi> logged in successfully.
        </li>
        <li>
          <strong>Word Break Opportunity:</strong> A long string like
          <code>super<wbr />cali<wbr />fragi<wbr />listic<wbr />expialidocious</code>
          can break cleanly.
        </li>
        <li>
          <strong>Ruby Annotations (East Asian Typography):</strong>
          <ruby>漢 <rt>かん</rt> 字 <rt>じ</rt></ruby>
        </li>
        <li>
          <strong>Presentational Inlines:</strong> Use <b>bold text</b> for visual
          draw without added importance, <i>italicized text</i> for idiomatic
          terms, <u>unarticulated annotation</u> for proper names in specific
          languages, or <small>small print</small> for legal disclaimers.
        </li>
      </ul>
