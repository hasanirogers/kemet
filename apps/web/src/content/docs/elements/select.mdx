The select element supports attributes of a standard select element with a few additions.


## Examples
<hr />

### Rounded

The select element supports standard `rounded` attribute sizes.

<CodePreview code='<kemet-select rounded><kemet-select-option value="1" label="Option 1"></kemet-select-option><kemet-select-option value="2" label="Option 2"></kemet-select-option></kemet-select>' language="html" />

### Filled

Fill the select with the `filled` attribute.

<CodePreview code='<kemet-select filled><kemet-select-option value="1" label="Option 1"></kemet-select-option><kemet-select-option value="2" label="Option 2"></kemet-select-option></kemet-select>' language="html" />

### Appearance

Change the appearance of the select with the `appearance` attribute.

<CodePreview code='<kemet-select appearance="success"><kemet-select-option value="1" label="Option 1"></kemet-select-option><kemet-select-option value="2" label="Option 2"></kemet-select-option></kemet-select>' language="html" />
