## Examples

### Square Handle

Use the `squared` attribute to make the toggle handle square.

<CodePreview>
  <kemet-toggle label="Label" squared></kemet-toggle>
</CodePreview>

### Show Options

You can show labels for the options you are toggling between.

<CodePreview>
 <kemet-toggle label="Use dark mode?" show option-unchecked="Light" option-checked="Dark"></kemet-toggle>
</CodePreview>
