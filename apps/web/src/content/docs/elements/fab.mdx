## Examples

### Outlined

Use the `outlined` attribute to create an outlined FAB.

<CodePreview>
  <kemet-fab outlined>
    <kemet-icon slot="icon" name="envelope" size="24"></kemet-icon>
    <span>Email</span>
  </kemet-fab>
</CodePreview>

### Rounded

The fab support standard rounded sizes.

<CodePreview>
  <kemet-fab rounded="pill">
    <kemet-icon slot="icon" name="envelope" size="24"></kemet-icon>
    <span>Email</span>
  </kemet-fab>
</CodePreview>


### Appearance

Change the color of the FAB using the `appearance` attribute.

<CodePreview>
  <kemet-fab appearance="brand">
    <kemet-icon slot="icon" name="envelope" size="24"></kemet-icon>
    <span>Email</span>
  </kemet-fab>
</CodePreview>


### Multiple fabs

You can stack multiple FABs together to create a more complex interface.

<CodePreview code={`<style>
  .fabs {
    display: flex;
    flex-direction: column;
    align-items: flex-end;
    gap: 1rem;
    position: relative;
    padding: 0;
    margin: 0;
    list-style: none;
  }
</style>
<ul class="fabs">
  <li>
    <kemet-fab rounded="pill">
      <kemet-icon slot="icon" name="envelope" size="24"></kemet-icon> Email

  </li>
  <li>
    <kemet-fab rounded="pill">
      <kemet-icon slot="icon" name="calendar" size="24"></kemet-icon> Calendar

  <li>
    <kemet-fab rounded="pill">
