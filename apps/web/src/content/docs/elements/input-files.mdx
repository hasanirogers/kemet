<Callout>
  Input file is just a UI component. You'll need to combine it with your own upload script. You can do this by listening to the `kemet-input-files-change` event. This event will give you the files that have been added. You'll need to dynamically insert a `kemet-input-file` element for each of these files in the event. [Here's an example script that demonstrates how to do this](https://stackblitz.com/edit/kemet-upload-example).
</Callout>
