## Examples

### Digits

Use the `digits` attribute to specify the number of digits in the OTP.

<CodePreview>
  <kemet-input-otp digits="6"></kemet-input-otp>
</CodePreview>

### Pattern

Use the `pattern` attribute to specify the pattern of the OTP.

<CodePreview>
  <kemet-input-otp pattern="[^A-Za-z0-9]"></kemet-input-otp>
</CodePreview>
