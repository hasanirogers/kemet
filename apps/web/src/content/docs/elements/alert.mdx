## Examples
<hr />

<br />
<Callout>
  By default, the alert is closed because it's expected to be triggered by demand. Set the `opened` attribute to display the alert.
</Callout>


### Closable

Use the `closable` attribute to make the alert closable.

<CodePreview code='<kemet-alert opened closable>Your message here.</kemet-alert>' language="html" />

### Appearance

You can change the color of the alert to any of the appearance colors.

<CodePreview code='<kemet-alert opened appearance="brand">Your message here.</kemet-alert>' language="html" />

### Border Appearance

You can add a border to any side of the alert.

<CodePreview code='<kemet-alert opened border-appearance="left">Your message here.</kemet-alert>' language="html" />

### Rounded

Alert supports the standard rounded sizes.

<CodePreview code='<kemet-alert opened rounded="lg">Your message here.</kemet-alert>' language="html" />

### Filled

You can invert the colors of the alert by setting the `filled` attribute.

<CodePreview code='<kemet-alert opened filled>Your message here.</kemet-alert>' language="html" />
