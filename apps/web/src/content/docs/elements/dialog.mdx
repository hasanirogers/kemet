### Close on click

You have the dialog close by clicking outside of it's content by using the `close-on-click` attribute.

<CodePreview code={`
  <script>
    const button = shadowRoot.querySelector('kemet-button');
    const dialog = shadowRoot.querySelector('kemet-dialog');
    button.addEventListener('click', function() {
      dialog.opened = true;
    });
  </script>
  <kemet-button>Open Modal</kemet-button>
  <kemet-dialog close-on-click>
